# Third-party components

See [Bootstrap's license](https://github.com/twbs/bootstrap/blob/main/LICENSE).

MySQL Connector/J is required at runtime but is not committed to this repository. Install a compatible Connector/J 8.x JAR in `web/WEB-INF/lib/` as described in the README, and review its license from the distributor.
